# 折叠屏小说金刚流宽度

‍

变动概述：  
使用容器实际宽度：从 `DisplayUtils.getScreenWidthPixels()`​ 改为 `itemView.width`​，确保layout变化时捕捉到实际宽度  
添加宽度监听：Fragment 和 ViewHolder 两层监听，确保宽度变化时及时适配  
延迟绑定：使用 `post`​ 确保 View layout 完成后再计算宽度，防止在 View 未完成 layout 时获取宽度  
修复 DiffUtil：原有未比较width，改为显式比较 `width` 字段，确保宽度变化时触发更新

首页小说页上层tab每个item均支持屏幕宽度变化时自适应宽度，刷新时状态稳定
